
# Management System

A full-stack management system built using Next.js, React, TypeScript, NestJS, PostgreSQL, and Prisma.

## Tech Stack

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS

### Backend
- Node.js
- NestJS
- TypeScript

### Database
- PostgreSQL
- Prisma ORM

## Project Structure

- frontend - Frontend application
- backend - Backend API application

## Project Status

Currently under development.
